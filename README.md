# Customer Journey Analytics + Data Visualization Tool

**Tech Stack:** Python · SQL · PostgreSQL · React · Plotly

## Overview
Analytics tool that stitches customer events (page views, clicks, sign-ups, purchases) into per-customer journeys. Provides funnel and drop-off views, cohort filters, and an interactive dashboard showing where customers leave and which paths lead to conversion.

## Features
- Event aggregation and journey reconstruction
- Funnel analysis with drop-off metrics
- Cohort filtering and segmentation
- Interactive Plotly dashboard
- Non-technical user interface
